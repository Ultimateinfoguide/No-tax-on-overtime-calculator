# 🇺🇸 No Tax on Overtime Calculator (Dev Edition)

A lightweight, privacy-first web tool designed for developers, freelancers, and contractors to instantly estimate the impact of the proposed 2026 "No Tax on Overtime" policy on their take-home pay.

🚀 **[View the Live Developer Calculator Here](https://ultimateinfoguide.github.io/No-tax-on-overtime-calculator/)**

## 📌 Why We Built This
Most financial calculators are bloated with unnecessary scripts and pop-ups. We built this static, dark-mode estimator to give tech professionals a lightning-fast way to run their baseline overtime numbers without breaking their workflow. 

All calculations run 100% locally in your browser via strictly encapsulated Vanilla JavaScript. Zero personal financial data is sent to external servers.

## ⚙️ Core Features
* **Zero Dependencies:** Built with pure Vanilla JS inside an IIFE. No frameworks, no external libraries.
* **Dark Mode Native:** Styled specifically for developer environments and reduced eye strain.
* **Instant Delta Calculation:** Real-time visual comparison between standard take-home pay and the proposed "Zero Tax on OT" take-home pay.

## 📊 For Complex W-2 & State Tax Scenarios
This repository serves as a baseline estimator assuming flat 1.5x scaling and generalized federal brackets for 1099/contract work.

## 🛠️ Local Usage 
Because this is a strictly encapsulated single-file deployment, running it locally is instant:
1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. No build steps, no `npm install`, and no server required.
